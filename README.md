# Mebel Lili — React site

Готовый адаптированный сайт компании **Mebel Lili (Самара)**. В проекте сохранена визуальная логика и механика референса: фиксированный хедер, поведение при скролле, мобильное меню, sticky-секции, горизонтальная галерея и адаптивная сетка. Тексты и изображения заменены на материалы Mebel Lili из предоставленного архива.

## Быстрый запуск без установки зависимостей

Для статической сборки достаточно Node.js 22; установка React/Vite не требуется.

```bash
npm run build
node server.mjs
```

После запуска откройте:

```text
http://localhost:4173
```

На Windows можно также запустить `START_WINDOWS.bat` или `START_WINDOWS.ps1`.

## Разработка

```bash
npm install
npm run dev
```

## Production-сборка

Основная production-сборка не требует Vite и собирается локальным скриптом:

```bash
npm run build
npm start
```

Если нужно проверить именно React/Vite-сборку после установки зависимостей:

```bash
npm run build:vite
```

## Персональные данные и приём заявок в РФ

По выбору пользователя от 04.10.2026 сайт и приём заявок подготовлены для **российского хостинга**. Все три формы отправляют JSON в `/api/leads` и требуют отдельного согласия, снятого по умолчанию. Заявка и подтверждение согласия сохраняются на российском сервере в зашифрованный файл AES-256-GCM. Только успешная запись подтверждает приём и очищает форму. Telegram необязателен: получает фиксированное уведомление и случайный номер, без имени, телефона, типа мебели и комментария. Ошибка уведомления не отменяет принятую заявку.

Реквизиты в `legal/operator.mjs` пока **плейсхолдеры**, документы — проекты. Сбор заблокирован до заполнения и утверждения оператора и настройки российского сервера. Подробная инструкция, доступ к очереди, удаление, правовые источники и оставшиеся действия владельца: [docs/LEGAL_IMPLEMENTATION.md](docs/LEGAL_IMPLEMENTATION.md).

Публичные документы: `/privacy.html`, `/consent.html`, `/cookies.html`. Они генерируются из `src/legal-documents.mjs` и `legal/operator.mjs` при сборке; `npm run build:legal` обновляет только документы. В коде нет cookies и аналитических трекеров; отдельный cookie-баннер не нужен для текущей реализации. Конфигурацию провайдера нужно проверить до запуска.

Серверные переменные (`.env.example`, без префикса `VITE_`):

| Переменная | Назначение |
| --- | --- |
| `LEADS_RU_HOSTING_CONFIRMED` | `true` после проверки размещения сайта и постоянного хранилища в РФ |
| `LEADS_DATA_DIR` | Абсолютный приватный каталог вне приложения на постоянном российском диске |
| `LEADS_ENCRYPTION_KEY` | 32 случайных байта в виде 64 hex-символов; хранить отдельно от данных |
| `TRUST_PROXY` | Только для доверенного закрытого прокси, заменяющего X-Forwarded-For |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Необязательные реквизиты бота для уведомлений с номером |

Запуск: `node --env-file=.env.local server.mjs`. Очередь читается уполномоченным лицом через SSH и `scripts/leads-admin.mjs` (`list`, `read ID`, `delete ID`, `purge`). Публичного API чтения нет. По достижении цели/обоснованному отзыву запись удаляется оператором; максимальный срок — 30 дней с автоматической очисткой. На сервере требуется независимый ежедневный запуск очистки на случай остановки приложения.

Vercel остаётся пригоден для просмотра статического проекта, **приём заявок в его функции заблокирован**: российских регионов функций в [официальном перечне](https://vercel.com/docs/regions) нет. Добавление только Telegram-переменных не включает сбор данных. Реальный российский сервер и бот пока не подключены.

`npm test` проверяет согласие, версию, все три формы, валидацию, ограничения, блокировку неподготовленной конфигурации, ошибки хранилища, отсутствие полей клиента в уведомлении и работу зашифрованных записей/удаления. Внешние отправки в тестах имитируются. Для разработки через Vite запустите Node-сервер на 4173 и `npm run dev` в другом терминале: `/api` проксируется к серверу.

## Визуальная система и источники

`src/fallback.css` — единственный источник дополнительных стилей; статическая сборка создаёт файл с content hash. `src/pageMarkup.js` хранит читаемую разметку секций. Шрифты Jost и IBM Plex Mono размещены локально, лицензии OFL — в `public/fonts`.

Подтверждённые фотографии перечислены в `docs/verified-photos.json`, бизнес-факты и визуальный эталон — в `docs/BASELINE.md`, классификация прежних изображений — в `docs/media-sources.json`. Галерея содержит семь фото из карточки Яндекс. Старые иллюстративные файлы сохранены в архиве проекта, но не используются как выполненные работы.

По указанию пользователя от 04.10.2026 hero использует `kitchen-modern.webp` — версию предоставленного `Modern L-Shaped Kitchen Interior-1.png`. Это иллюстрация интерьера, без подписи выполненного заказа. Порядок меню соответствует странице: Главная → Мебель → Отзывы → Проекты → Контакты.

На экранах шириной до 767 px элемент `picture` переключает hero на вертикальный `kitchen-modern-mobile.webp` из `Modern L-Shaped Kitchen Interior-2.png` (1086×1448). На более широких экранах остаётся горизонтальное изображение.

Логотип заменён на предоставленный `White Lily Furniture Logo.png`: файл `public/assets/lili-logo.png` сохраняет исходный RGBA и прозрачность без изменения пикселей. В шапке отображается 44×44 px, в основном блоке подвала — 145×145 px; заменены также дополнительный знак в подвале и favicon. На светлой шапке логотип затемняется CSS-фильтром, на hero и в тёмном подвале остаётся белым.

Состояние выполнения плана — `MILESTONES.md`, результаты финальных проверок — `docs/VERIFICATION.md`. Запуск требует Node.js 22.
