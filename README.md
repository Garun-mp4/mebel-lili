# Mebel Lili — React site

Готовый адаптированный сайт компании **Mebel Lili (Самара)**. В проекте сохранена визуальная логика и механика референса: фиксированный хедер, поведение при скролле, мобильное меню, sticky-секции, горизонтальная галерея и адаптивная сетка. Тексты и изображения заменены на материалы Mebel Lili из предоставленного архива.

## Быстрый запуск без установки зависимостей

В архив уже включена готовая папка `dist`.

```bash
node server.mjs
```

После запуска откройте:

```text
http://localhost:4173
```

На Windows можно также запустить `START_WINDOWS.bat` или `START_WINDOWS.ps1`.

## Разработка

```bash
npm install
npm run dev
```

## Production-сборка

Основная production-сборка не требует Vite и собирается локальным скриптом:

```bash
npm run build
npm start
```

Если нужно проверить именно React/Vite-сборку после установки зависимостей:

```bash
npm run build:vite
```

## Формы

На сайте размещены три формы: в hero-блоке, промежуточная форма и финальная форма контакта. По текущему ТЗ отправка является демонстрационной: после отправки пользователь видит явное сообщение, что заявка фактически не была отправлена. Реальное подключение Telegram Bot API можно добавить позже без изменения дизайна форм.

## Контент

- Контакты, направления, рейтинг и отзывы основаны на предоставленном архиве компании.
- Не добавлены неподтверждённые гарантии, сроки, бренды материалов или другие факты, которых не было в исходных данных.
- Краткий анализ ЦА и логика офферов находятся в `CONTENT_STRATEGY.md`.
