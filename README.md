# Mebel Lili — React site

Готовый адаптированный сайт компании **Mebel Lili (Самара)**. В проекте сохранена визуальная логика и механика референса: фиксированный хедер, поведение при скролле, мобильное меню, sticky-секции, горизонтальная галерея и адаптивная сетка. Тексты и изображения заменены на материалы Mebel Lili из предоставленного архива.

## Быстрый запуск без установки зависимостей

Для статической сборки достаточно Node.js 22; установка React/Vite не требуется.

```bash
npm run build
node server.mjs
```

После запуска откройте:

```text
http://localhost:4173
```

На Windows можно также запустить `START_WINDOWS.bat` или `START_WINDOWS.ps1`.

## Разработка

```bash
npm install
npm run dev
```

## Production-сборка

Основная production-сборка не требует Vite и собирается локальным скриптом:

```bash
npm run build
npm start
```

Если нужно проверить именно React/Vite-сборку после установки зависимостей:

```bash
npm run build:vite
```

## Формы и Telegram на Vercel

Все три формы отправляют JSON в `/api/leads`. Vercel запускает `api/leads.js`; локальный `server.mjs` использует тот же обработчик `server/leads.mjs`. Токен не попадает в браузер. Поля очищаются только после подтверждённого ответа Telegram с ID сообщения. До подключения бота возвращается 503 с предложением позвонить; поля сохраняются. Есть состояния ожидания, сетевой ошибки, отказа Telegram и ограничения частоты.

В Vercel импортируйте этот GitHub-репозиторий. `vercel.json` задаёт сборку `npm run build`, каталог `dist` и функцию API. В Settings → Environment Variables добавьте **две серверные переменные** для Production (и Preview, если нужно):

| Переменная | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен вашего бота от BotFather |
| `TELEGRAM_CHAT_ID` | ID чата, которому бот может писать; для группы обычно начинается с `-100` |

Запустите личный диалог с ботом либо добавьте бота в выбранную группу и разрешите отправку сообщений. Затем повторно разверните сайт, чтобы новые переменные применились. Префикс `VITE_` для этих переменных не использовать. Никакого изменения кода для подключения бота не требуется. Руководства: [переменные Vercel](https://vercel.com/docs/environment-variables), [Node.js Functions](https://vercel.com/docs/functions/runtimes/node-js), [Telegram sendMessage](https://core.telegram.org/bots/api#sendmessage).

Локально скопируйте `.env.example` в `.env.local`, заполните две переменные и запустите `node --env-file=.env.local server.mjs`. `.env.local` исключён из Git. Для разработки через Vite запустите сервер на 4173 и `npm run dev` в другом терминале: `/api` проксируется к серверу.

`npm test` проверяет валидацию, все три источника заявки, отказ API, подтверждение доставки, недоступную конфигурацию и ограничения. Ответ Telegram в тестах имитируется; тесты не отправляют сообщений. Проверить реальный чат можно после настройки настоящего бота.

Ограничение частоты — пять запросов в минуту на IP в одном экземпляре обработчика. При масштабировании Vercel это не глобальный лимит; при необходимости усилить его используйте Vercel Firewall. Есть скрытое поле для отсечения простых ботов и проверка Origin. Автоматических повторных отправок нет, чтобы не дублировать заявки при неопределённом сетевом результате.

## Визуальная система и источники

`src/fallback.css` — единственный источник дополнительных стилей; статическая сборка создаёт файл с content hash. `src/pageMarkup.js` хранит читаемую разметку секций. Шрифты Jost и IBM Plex Mono размещены локально, лицензии OFL — в `public/fonts`.

Подтверждённые фотографии перечислены в `docs/verified-photos.json`, бизнес-факты и визуальный эталон — в `docs/BASELINE.md`, классификация прежних изображений — в `docs/media-sources.json`. Галерея содержит семь фото из карточки Яндекс. Старые иллюстративные файлы сохранены в архиве проекта, но не используются как выполненные работы.

Состояние выполнения плана — `MILESTONES.md`. Запуск требует Node.js 22.
