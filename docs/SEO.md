# SEO — состояние и подключение

Основной адрес: https://mebel-lili.vercel.app/. Настройки и подтверждённые сведения о бизнесе централизованы в `seo/site.mjs`.

## Реализовано

- Статический HTML главной и трёх страниц услуг: `/kuhni-na-zakaz-samara/`, `/shkafy-na-zakaz-samara/`, `/korpusnaya-mebel-samara/`.
- Уникальные title/description, H1, заголовки разделов, ссылки между страницами и видимые хлебные крошки.
- Абсолютный self canonical, Open Graph и Twitter Card с существующими фотографиями и их описаниями.
- JSON-LD LocalBusiness, WebSite, WebPage; Service и BreadcrumbList на страницах услуг. Указаны Самара, телефон, адрес и карточка Яндекса. Неподтверждённые часы, цены, координаты и рейтинги в разметку не включены.
- Сборка создаёт robots.txt и sitemap.xml с четырьмя коммерческими URL. Черновики юридических документов сохраняют noindex и не входят в sitemap. lastmod не подменяется временем сборки.
- Redirect 308 для `/index.html`, страниц услуг без завершающего `/` и их `index.html`; конфигурация есть для Vercel и Node-сервера.
- Preview-сборки Vercel получают noindex/nofollow и robots Disallow. Два постоянных дополнительных адреса Vercel перенаправляются на основной; остальные публикации обозначают основную страницу через canonical. Доступ и защиту preview нужно сохранять в настройках проекта.
- Runtime запускается на готовом HTML без повторной вставки всей страницы. Фото имеют размеры, второстепенные изображения — lazy loading; CSS объединён и минифицирован средствами существующего Vite, JS минифицирован. Файлы имеют content hash и длительный cache-control. Node-сервер поддерживает gzip текстовых ресурсов; Vercel сжимает их на своей стороне.

Production: `npm run build`. Перед `npm test` нужна свежая production-сборка: SEO-тесты проверяют артефакты `dist/`. Vite используется для разработки; поисковая доступность без JS обеспечивается именно статической production-сборкой.

## Действия в кабинетах владельца

1. Подтвердить сайт в Яндекс Вебмастере: https://webmaster.yandex.ru/. Предпочтительно выдать строку meta verification для вставки в head либо файл подтверждения в public. Для своего домена возможна DNS-проверка. Не передавать пароли в репозиторий.
2. Подтвердить URL-prefix https://mebel-lili.vercel.app/ в Google Search Console: https://search.google.com/search-console/. Строка подтверждения/файл берётся из аккаунта владельца.
3. Отправить https://mebel-lili.vercel.app/sitemap.xml в оба кабинета; проверить четыре URL инструментом проверки страниц и запросить обход доступным способом.
4. В Яндекс Вебмастере подтвердить регион Самара. В существующей карточке Яндекс Бизнеса https://yandex.com/maps/org/mebel_lili/1806470657 указать основной URL, проверить контакты, часы и фактическую территорию обслуживания.
5. Наблюдать индексирование, выбранные canonical, ошибки, запросы, показы и CTR. Регистрация и отправка пока не выполнены: требуется аккаунт владельца/доступ.

Для вставки выданных кодов проверок доступны серверные build-переменные `GOOGLE_SITE_VERIFICATION` и `YANDEX_SITE_VERIFICATION`. Они не являются паролями. После добавления необходима новая сборка. Пустые значения теги не создают.

## Что требует подтверждения

- Полное наименование оператора и реквизиты для юридических документов; российское размещение и включение заявок по существующей инструкции.
- Материалы и фурнитура, реальные диапазоны цен, сроки, условия замера/доставки/монтажа, гарантии и часы работы. Сейчас страницы не обещают неподтверждённые условия.
- Описания проектов: задача, размеры, материалы, согласованные сроки и разрешённые фотографии. Создавать страницы проектов нужно после получения этих сведений.
- Семантика Wordstat и сравнение фактической выдачи по Самаре: текущая архитектура построена по подтверждённым направлениям без заявления о частотности запросов.
- Если выбран новый домен: изменить SITE_URL, настроить единый HTTPS-хост и редиректы со старых адресов, обновить карточку и кабинеты поисковиков, пересобрать все metadata/sitemap. Адрес оператора в legal/operator.mjs меняется отдельно.

## Скорость и измерение

Локальные шрифты сжаты в WOFF2 без удаления глифов: Jost 134996 → 50656 байт, IBM Plex Mono 135580 → 39092 байт. Исходные TTF и лицензии сохранены. Для повторной конвертации в ходе разработки использован FontTools; зависимости production-сборки не добавлены.

Проверять мобильные страницы в PageSpeed Insights https://pagespeed.web.dev/; Lighthouse даёт лабораторный результат. Полевые Core Web Vitals оценивают реальные посещения: LCP ≤2.5 s, INP <200 ms, CLS <0.1. Отсутствие полевых данных у нового сайта не означает ошибку. Кабинеты поиска работают без клиентских счётчиков; добавление Метрики/маркетингового трекинга требует отдельной проверки технической и юридической настройки согласия.

Проверка 04.10.2026: сборка и 17 тестов проходят. Playwright проверил четыре страницы при ширине 1440 и 390 px, HTML без JS, меню, FAQ, переход к форме, отсутствие горизонтального переполнения/битых изображений и внутренние ссылки. robots/sitemap возвращают 200, дубли — 308, неизвестный URL — 404; согласия обязательные и изначально пустые. Ошибок runtime нет.

Финальный локальный Lighthouse 12.8.2 в мобильном режиме: SEO 100/100, accessibility 100/100, performance 84/100, LCP 4.3 s, CLS 0, TBT 60 ms. В измерении блокировался внедряемый антивирусом хоста адрес `*kaspersky-labs.com*`; исходники сайта не содержат этот скрипт. Это лабораторный замер localhost, не полевые Core Web Vitals и не оценка позиций. LCP ещё выше целевого: нужно сопоставлять с измерением публичного CDN и данными реальных посещений. Lighthouse не измеряет полевой INP этой проверкой.

Первичная проверка страниц конкурентов Самары показывает важность материалов, условий замера/монтажа и примеров стоимости. Источники для дальнейшей работы: https://mebelnyy1.ru/kuhni и https://www.asp-samara.ru/. Эти сведения относятся к конкурентам; их условия не перенесены на Mebel Lili. Частотность Wordstat и региональные позиции не измерялись.
